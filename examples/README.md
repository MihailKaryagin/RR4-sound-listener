# Подготовленные примеры поклёвок

Исходные видео не изменялись:

- `krasnaya.mp4` — красная удочка;
- `sinaya.mp4` — синяя удочка;
- `zelenaya.mp4` — зелёная удочка.

В `extracted/` находятся полные звуковые дорожки WAV, mono 16 кГц.
В `prepared/` — по два коротких положительных образца каждого звука (примерно 0,76–0,83 секунды), а также `validation.json` с границами фрагментов и результатами проверки.

Образцы также установлены в `%LOCALAPPDATA%\RF4Notifier\samples`. Перезапусти приложение, если оно было открыто: при запуске окна перечитывается список образцов. При переносе на другой ПК скопируй туда WAV из `prepared/` в эту папку или импортируй их через приложение.

Для воспроизведения подготовки из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install "imageio-ffmpeg>=0.6,<0.7"
.\.venv\Scripts\python.exe tools\inspect_examples.py
.\.venv\Scripts\python.exe tools\prepare_examples.py --install
```

Это дополнительная зависимость только для извлечения аудио; готовому приложению она не нужна. Дорожки извлекаются локально, без загрузки видео в сеть. Существующие отличающиеся образцы в папке приложения не перезаписываются.

Для шаблонов взяты первые два полных сигнала каждого ролика. Остальные полные сигналы используются для проверки совпадения. Дополнительно проверяется обработка каждого ролика порциями по 250 мс при исходной и уменьшенной в четыре раза громкости: при пороге 0,78 и паузе 30 секунд ожидается одно срабатывание на ролик.

**Ограничение:** повторы из одного ролика — не независимые игровые сессии. Эти результаты не измеряют ложные срабатывания на игровом фоне. Нужна отдельная проверка на обычных звуках игры и новых поклёвках. Процент совпадения не является вероятностью правильного обнаружения.

# РР4 · Звуковой сторож

Локальное Windows-приложение для уведомления в Telegram по звуку поклёвки в «Русской рыбалке 4». Захватывает звук выбранных наушников или динамиков через WASAPI loopback. Не читает память игры, не нажимает клавиши и не выполняет игровых действий.

## Новый интерфейс — Bite Watch 2.0

Оформление обновлено по примеру из `primer/`: тёмно-синяя палитра, фиолетовые и коралловые акценты, боковая навигация и карточки показателей. Настройки и WAV-образцы остались в прежней папке `%LOCALAPPDATA%\RF4Notifier`; повторный ввод сохранённого токена не требуется, если используется тот же аккаунт Windows.

- **Обзор:** запуск, проверка без Telegram, остановка, график последних 30 секунд, журнал, число срабатываний за время работы приложения. График отображает реальные поступающие аудиоданные. Уровень звука — относительная шкала, не дБ.
- **Telegram:** токен, chat ID, тест сообщения, сохранение. Состояние «Не проверен» после открытия нормально: приложение не делает сетевой запрос само. Для проверки нажми «Тест сообщения».
- **Образцы звуков:** запись, импорт WAV, открытие папки, удаление выбранного образца. Подготовленные красная, синяя и зелёная удочки подписаны по-русски.
- **Настройки:** выбор аудиовыхода, порог совпадения, пауза, сохранение. Изменения применяются при следующем запуске мониторинга.

Быстрый старт: **Настройки → выбрать выход → Telegram → проверить сообщение → Обзор → Проверка без Telegram → Стоп → Запустить мониторинг**. Проверка без Telegram также увеличивает счётчик срабатываний, но сообщений не отправляет. Минимальный размер клиентской области окна — 1100×780.

## Что реализовано

- Окно на русском, выбор выхода звука Windows, индикатор уровня.
- Запись образцов с системного выхода и импорт WAV.
- Редактор с волной, обрезкой начала/конца и прослушиванием.
- Несколько положительных и отрицательных образцов.
- Локальное распознавание по log-mel-спектрограммам: нормализованная корреляция со сдвигом по времени и небольшим изменением скорости.
- Порог совпадения, гистерезис и пауза между уведомлениями.
- Проверка распознавания без Telegram, тест Telegram, журнал состояния.
- Отправка по HTTPS в отдельном потоке. Записи не отправляются в облако.
- Токен хранится зашифрованным средствами Windows DPAPI для текущего пользователя.

Это **распознавание по примерам, а не обученная нейросеть**. Для конкретного повторяющегося игрового звука это хороший проверяемый старт. Точность на реальных поклёвках нужно измерить; без твоих записей готовой модели игры нет. Процент совпадения — оценка сходства, не вероятность поклёвки.

## Запуск

**Готовая сборка на этом ПК:** `F:\ribalka\dist\RF4Notifier\RF4Notifier.exe`. Открой двойным щелчком — Python для неё не нужен. Рядом должна оставаться папка `_internal`. Запуск окна и корректное закрытие собранного EXE проверены.

Для запуска из исходников:

Требуется Windows 10/11 x64 и Python **3.12 x64** с компонентом Tcl/Tk и Python Launcher. Зависимости для этой версии проверены. Микрофон не нужен, права администратора не нужны.

1. Один раз запусти `install.bat`.
2. Затем запускай `start.bat`.

Либо из PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Настройка Telegram

1. Открой **@BotFather** в Telegram, выполни `/newbot` и получи токен.
2. Открой чат со своим новым ботом и нажми **Start** / отправь `/start`.
3. Узнай свой числовой chat ID. Для личного чата его можно посмотреть через **@userinfobot**, понимая, что это сторонний бот. Альтернатива без стороннего бота — метод `getUpdates` официального Telegram Bot API после сообщения своему боту: поле `message.chat.id`. Не публикуй URL с токеном.
4. Вставь токен и chat ID **в окно программы**, нажми «Тест сообщения».
5. Нажми «Сохранить».

Не присылай токен в переписку, не добавляй его в исходники и скриншоты. Если он утёк — отзови его через @BotFather. DPAPI не защищает от вредоносной программы, работающей под тем же пользователем Windows.

## Запись и настройка распознавания

1. Выбери **тот выход**, на который действительно играет РР4. Если игра выведена на отдельное устройство в микшере Windows, выбери именно его.
2. Временно выключи музыку, голосовые чаты и посторонние уведомления. Loopback слышит **все приложения на выбранном выходе**, а не только игру.
3. Нажми «Записать», пока звучит поклёвка. По умолчанию записывается 6 секунд; можно поставить до 20. Если момент трудно поймать, используй готовую запись WAV.
4. В редакторе двумя ползунками оставь короткий характерный фрагмент, желательно **0,5–2 секунды**. Прослушай его и сохрани как «Поклёвка». Максимальная длина образца — 8 секунд.
5. Добавь **3–5 примеров** из разных реальных поклёвок. Если у разных снастей разные сигналы, нужны отдельные образцы каждого сигнала.
6. Добавь несколько типичных похожих звуков как «Не поклёвка»: ложные звуки сохраняются отдельно и могут блокировать срабатывание. Не включай настоящую поклёвку в отрицательный пример.
7. Нажми **«Проверка без Telegram»**. Начальный порог — **0,78**. Смотри на совпадение при поклёвке и на фоне.
8. При пропусках попробуй немного снизить порог или записать более чистый образец. При ложных срабатываниях — повысить порог, обрезать фон и добавить отрицательный пример. После изменения параметров останови и запусти распознавание заново.
9. Нажми «Стоп», затем **«Запустить»** для уведомлений в Telegram.

Не подбирай порог только на тех же записях, которые добавлены в образцы: проверь на новых поклёвках и хотя бы 10–15 минутах обычного фона. Для оценки качества полезно записывать число настоящих поклёвок, пропусков и ложных уведомлений. Нельзя гарантировать отсутствие ложных срабатываний.

## Задержка и защита от повторов

Звук анализируется примерно раз в 250 мс. Распознавателю нужно услышать характерный фрагмент целиком, затем добавляется время сети и доставки Telegram. Мгновенная доставка и строго фиксированная задержка не гарантируются.

После срабатывания действует пауза (по умолчанию **30 секунд**). Для повторного взведения звук также должен перестать совпадать как минимум на секунду. Пока старый сигнал находится в анализируемом окне, он может считаться продолжающимся. Поэтому не делай образцы длиннее необходимого. Близкие или одновременные поклёвки могут объединяться в одно уведомление; программа не определяет номер удочки.

При ошибке сети сообщение записывается как неотправленное в журнал; автоматических повторов нет, чтобы не получить запоздалые или дублирующиеся уведомления. «Telegram принял сообщение» означает принятие сервером, а не прочтение на телефоне.

## Где лежат данные

```text
%LOCALAPPDATA%\RF4Notifier\config.json
%LOCALAPPDATA%\RF4Notifier\samples\*.wav
```

В конфигурации токен зашифрован, chat ID и остальные настройки хранятся открыто. Образцы — обычные локальные WAV: они могут случайно содержать голоса или другую личную информацию. Не публикуй их без проверки. Для резервной копии можно сохранить папку образцов. Зашифрованный токен нельзя просто перенести на другой аккаунт Windows: там введи его заново.

## Ограничения

- Это внешний аудионаблюдатель, но допустимость такого софта определяется правилами игры. Отсутствие вмешательства в процесс **не гарантирует**, что использование разрешено. Проверь актуальные правила или уточни у поддержки РР4.
- Звук должен реально выводиться Windows. Выключенный звук игры, смена устройства, сон ПК, отключение наушников или отсутствие сети мешают работе.
- Bluetooth-переключение профиля гарнитуры может менять устройство. После смены выхода нажми «Стоп», «Обновить» и выбери новый выход.
- Программа продолжает работать при свёрнутом окне, но не после закрытия. Системный трей и автозапуск пока не реализованы.
- Нет изоляции звука по процессу, нейросетевого обучения, определения снасти, гарантированной доставки или готовых звуков из ресурсов игры.
- Чем больше и длиннее образцы, тем выше нагрузка на процессор. Начни с нескольких коротких записей.

## Проверки и сборка EXE

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\gui_smoke.py
```

Дополнительная проверка с кратким захватом системного аудио (без отправки Telegram и изменения настроек):

```powershell
.\.venv\Scripts\python.exe tests\gui_smoke.py --live-audio
```

Проверки используют синтетические сигналы и не подтверждают точность на настоящей игре. GUI smoke test кратковременно открывает и закрывает окно. Тесты не отправляют реальные сообщения Telegram.

Для повторной сборки переносимой папки Windows-приложения запусти `build_exe.bat`. Результат: `dist\RF4Notifier\RF4Notifier.exe`. Переноси **всю** папку `RF4Notifier`, не один EXE. Для сборки нужен интернет; для использования собранного приложения Python не нужен.

Проверено на текущем ПК: 17 автоматических тестов, открытие окна и редактора, короткий захват loopback-аудио, запуск и закрытие собранного EXE. Реальная поклёвка и доставка в Telegram требуют твоих образцов и реквизитов бота и пока не проверены.
